# 使い方

このzipの中身をUnityプロジェクトのルートにコピーしてください。

配置後の構成：

```plain text
YourUnityProject/
├── AGENTS.md
├── Docs/
│   ├── prototype_spec.md
│   └── implementation_plan.md
├── Assets/
├── Packages/
└── ProjectSettings/
```

Codexには、まず以下のように依頼してください。

```text
Read AGENTS.md, Docs/prototype_spec.md, and Docs/implementation_plan.md.
Then implement Phase 1 only.
Do not implement later phases yet.
```

最初から全部作らせず、Phase 1 → Phase 2 → Phase 3 の順で進めてください。
